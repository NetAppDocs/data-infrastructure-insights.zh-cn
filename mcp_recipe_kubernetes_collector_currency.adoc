= 检查 Kubernetes 收集器时效性
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
使用此方案可识别 DII operator 或收集组件已过时、已禁用或陈旧的 Kubernetes 集群。


NOTE: DII MCP 是一link:concept_preview_features.html["预览"]项功能，因此可能会发生变化。



[[prerequisites]]
== 前提条件

* 已在 DII 租户中配置 Kubernetes 集合。
* 访问 Kubernetes 收集器信息。




[[tools-used]]
== 使用的工具

* +OperatorsManagement_getKubernetesCollectors+
* 可选：+AcquisitionUnitsService_getAcquisitionUnits+
* 可选：+CollectorService_getDataSources+




[[starter-prompt]]
== 入门提示

[]
====
查看 DII Kubernetes 收集器的时效性。按总体状态对集群进行分组，识别过时或禁用的 Operator 和组件，并标记过时的上次报告时间戳。不要显示内部地址或 UUID。

====


[[agent-workflow]]
== 代理工作流

. 列出 Kubernetes 收集器。
. 将每个集群规范化为：
+
** 最新
** 已过时
** 已禁用
** 未知


. 比较：
+
** Operator 版本
** 网络性能和映射组件版本
** 更改分析组件版本


. 将上次报告的时间戳转换为请求的时区。
. 标记未在约定的新鲜度阈值内报告的集群。
. 区别 `N/A`于过时的版本：
+
** `N/A` 可能表示组件未安装、未启用或不适用。


. 如果报告已过时，请检查相关的采集单元和采集器状态（如有）。
. 返回优先升级和调查列表。




[[interpretation]]
== 解释

* *过期：* 至少有一个已安装的组件落后于 DII 预期版本。
* *已禁用：* 收集已被有意或在管理上禁用。
* *过时报告：* 版本数据可能无法反映集群的当前状态。
* *N/A:* 需要上下文；不要自动将其分类为失败。


此工具报告版本和状态。它不执行升级。



[[suggested-output]]
== 建议输出

. 按状态分类的集群计数
. 按报告新鲜度排序的过时集群
. 组件级版本差异
. 已禁用或不可用的组件
. 建议的验证步骤




[[limits-and-privacy]]
== 限制和隐私

* 集群名称可能是敏感信息；在共享结果时请使用经批准的处理方式。
* 请勿仅凭版本的新旧程度来推断漏洞暴露情况。
* 验证此只读工作流之外的升级兼容性和过程。
