= DII MCP 概念和数据模型
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
理解这些概念有助于 AI 助手选择正确的工具并构建有效的查询。


NOTE: DII MCP 是一项 link:concept_preview_features.html["预览"] 功能，因此可能会发生变化。



[[tenant-scope]]
== 租户范围

每个 DII MCP 请求都在经过身份验证的用户的 DII 租户和权限内运行。工具只能返回存在于该租户中且对该身份可见的数据。



[[acquisition-units]]
== 采集单元

采集单元（AU）是一种远程安装的代理，用于轮询数据源并将遥测数据报告给 DII。AU 记录包括连接状态、报告新鲜度、操作系统、版本以及分配的数据源数量。

连接和报告是不同的信号。例如，AU 可以在没有成功报告历史记录的情况下接受连接。评估状态和 `lastReported`。



[[data-sources]]
== 数据源

数据源（也称为收集器）是与基础架构系统（如存储阵列、交换机、虚拟机管理程序或云服务）的配置连接。

使用列表操作获取清单和状态。当您需要收集包、轮询间隔或近期活动等配置详细信息时，检索特定数据源。

支持的数据源类型描述了更广泛的 DII 收集器目录。它们与当前租户中配置的收集器不同。



[[objects]]
== 对象

对象是标准化的基础架构实体，如存储系统、池、卷、主机、虚拟机、Kubernetes 工作负载和产品特定资源。

对象类型是动态的。始终：

. 列出对象类型。
. 选择确切的类型。
. 检索该类型的元数据。
. 仅查询元数据声明的属性和指标。




[[attributes-and-metrics]]
=== 属性和指标

* *属性*描述身份、配置、所有权、标签或关系。
* *指标*是随时间变化的测量值，例如容量、延迟、吞吐量或利用率。
* *可分组属性*可以对聚合查询进行分段。


在应用请求的时间窗口聚合之前，将根据原始指标值对指标筛选器进行评估。



[[logs]]
== 日志

日志类型表示事件流，例如 ONTAP EMS、Kubernetes 事件、StorageGRID 事件、VMware 事件和 DII 平台事件。

日志查询也是元数据优先：

. 列出可用的日志类型。
. 检索选定类型的元数据。
. 仅请求有效属性。
. 搜索事件或构建事件计数直方图。




[[monitors-and-alerts]]
== 监控和警报

监视器定义 DII 评估的条件。警报是一个或多个相关对象的特定监控结果。

* 使用监控工具检查意图、状态、对象类型和纠正指导。
* 在查询警报之前使用警报元数据。
* 使用警报名称（如 `AL-123456`或其 UUID）检索一个警报。


警报状态和严重程度是不同的维度。在确定结果的优先顺序时，同时询问两者。



[[maintenance-windows]]
== 维护窗口

维护窗口在定义的时间段内抑制与表达式匹配的警报。空的成功结果意味着不存在匹配的窗口；它不是缺失数据的证据。



[[notification-rules-and-targets]]
== 通知规则和目标

通知规则路由匹配的警报。目标可以包括 Slack、Microsoft Teams、PagerDuty 或自定义 HTTP 集成。

Webhook 地址可能包含机密信息。对于报告，仅请求目标名称、引擎类型和状态。切勿重现完整地址。



[[metadata-first-query-flow]]
== 元数据优先查询流

[source, text]
----
Discover types
    → retrieve type metadata
        → select valid attributes and metrics
            → query a bounded time range
                → paginate, group, or retrieve time series
----


[[filters]]
== 筛选器

DII 查询工具支持条件和嵌套逻辑运算符：

* 比较： `EQ`, `NE`, `GT`, `LT`, `GE`, `LE`
* 模式匹配： `WILDCARD`
* 出席： `EXISTS`
* 逻辑： `and`， `or`， `not`


使用元数据中声明的确切字段名称和兼容值类型。对于 `EXISTS`，如果连接的服务器版本支持，则省略比较值。



[[time-ranges-and-pagination]]
== 时间范围和分页

* 使用带有显式偏移或 `Z`的 ISO-8601 时间戳。
* 在需要时提供 IANA 时区，例如 +America/New_York+ 或 `UTC`。
* 将查询窗口保持为 30 天或更短，除非工具记录了较小的限制。
* 对象和警报查询通常使用 `limit`和 `offset`。
* 日志事件查询使用返回的游标获取下一页。


有关错误和恢复步骤，请参见 link:mcp_troubleshooting.html["故障排除"]。
