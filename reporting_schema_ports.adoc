|===

| 季度 | 字节 | 是 | 日期对象的季度。第一季度的值为 1。 


| quarterLabel | 字符串 | 是 | 季度格式化为字符串 


| dayInQuarter | Int32 | 是 | 日期对象的季度中的天。季度的第一天值为 1。 


| repQuarter | 字节 | 是 | 指示此日期是否是其季度的第一个可用日期。 


| repMonth | 字节 | 是 | 指示此日期是否是其月份的第一个可用日期。 


| repWeek | 字节 | 是 | 指示此日期是否是其一周内可用的第一个日期。 


| repDay | 字节 | 是 | 指示此日期是否是其当天可用的第一个日期。 


| repMonthOrLatest | 字节 | 是 | 指示此日期是代表月还是最新代表月。此标志由按月处理代表数据的 Datamarts 使用。唯一的区别在于当前月份使用的是最新数据 


| sspFlag | 字节 | 是 | 指示此日期是否在存储和存储池数据集市中使用。这适用于月代表和配置中定义的最后天数。 


| 最新 | 字符串 | 是 | 指示此日期是否为表中的最后一个可用日期。 


| 未来 | 字符串 | 是 | 指示此日期是未来日期（预测）还是常规日期。
