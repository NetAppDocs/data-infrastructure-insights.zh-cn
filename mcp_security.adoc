= 安全与隐私
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
DII MCP 服务器允许 AI 客户端访问租户基础架构上下文。请像对待 DII 用户界面和 API 一样谨慎对待该上下文。


NOTE: DII MCP 是一项 link:concept_preview_features.html["预览"] 功能，因此可能会发生变化。



[[least-privilege-access]]
== 最小权限访问

* 使用专用于连接到 MCP 的个人、应用程序或自动化的身份。
* 仅授予预期工作流程所需的 DII 读取权限。
* 当用户的角色或运营责任发生变化时，查看访问权限。
* 对于无人值守的自动化，请使用单独的服务标识。


此处记录的当前 DII 产品工具集是只读的。只读访问仍可泄露敏感名称、拓扑、配置、遥测和运行状态。



[[authentication]]
== 身份验证

首选交互式 OAuth 或部署支持的其他短期身份验证流。如果需要非交互式凭据：

* 将它们存储在经批准的机密管理器中。
* 根据组织策略确定范围并进行轮换。
* 切勿将它们放在项目文件、shell 历史记录、提示、屏幕截图或文档中。




[[sensitive-fields]]
== 敏感字段

潜在敏感的 DII 数据包括：

* IP 地址、主机名、租户特定的资源名称和 UUID
* 基础设施拓扑和配置
* 警报描述和日志有效载荷
* 用户、所有者、标签和标注值
* Webhook 端点地址


Webhook URL 通常嵌入路由密钥、签名、令牌或唯一路径。请勿要求代理返回完整的 Webhook 地址。仅请求：

* 目标名称
* 集成或引擎类型
* 已启用或交付状态


集成 MCP 服务器的应用程序应在显示、存储或转发工具结果之前隐去 Webhook 地址。



[[prompt-and-output-hygiene]]
== 提示和输出卫生

* 在可重复使用的提示和示例中使用虚构标识符。
* 要求代理省略 IP 地址、UUID、端点地址和原始日志负载，除非它们是必要的。
* 总结调查结果，而不是复制大量原始响应。
* 在将生成的内容放入工单、聊天频道或外部文档之前，请先对其进行审核。
* 遵循选定 AI 客户端的组织数据处理要求。




[[tenant-isolation]]
== 租户隔离

MCP 结果在租户范围内限定于经过身份验证的 DII 上下文。除非工作流和授权明确允许，否则请勿合并来自多个租户的结果。



[[audit-and-retention]]
== 审核和保留

审计事件的覆盖范围和保留取决于 DII 部署和连接的 AI 客户端。在生产使用之前，管理员应确认：

* 是否记录 MCP 身份验证和工具调用
* 保留哪些请求参数和结果元数据
* 谁可以查看这些记录
* AI 客户端保留提示和工具结果的时间


请勿假设存在特定于 MCP 的审核事件或保留保证，除非为您的部署记录了这些事件或保证。



[[incident-response]]
== 事件响应

如果凭据或包含凭据的端点出现在 MCP 结果、提示、文字记录或发布的文档中：

. 停止共享受影响的内容。
. 吊销或轮换凭据或集成密钥。
. 尽可能从存储的工件中删除该值。
. 查看访问和审核记录。
. 通过组织的安全流程报告暴露情况。
