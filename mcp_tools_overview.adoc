= DII MCP 工具参考
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
DII MCP 服务器目前在九个域中公开了 26 个只读产品工具。当连接的客户端需要进行身份验证时，可能会出现单独的 +mcp_auth+ 帮助程序。


NOTE: DII MCP 是一link:concept_preview_features.html["预览"]项功能，因此可能会发生变化。

工具可用性和结果取决于经过身份验证的租户、启用的 DII 功能、配置的收集器和用户权限。



[[query-conventions]]
== 查询约定

* 在查询动态字段之前发现类型和元数据。
* 使用元数据返回的精确、区分大小写的属性和指标名称。
* 必要时使用 ISO-8601 时间戳和 IANA 时区名称。
* 将查询窗口保持在 30 天或更短。
* 将 `limit`和 `offset`用于对象和警报分页。
* 使用返回的游标进行日志事件分页。
* 不显示完整的 Webhook 端点地址。

[[alerts]]
== 警报



[[get-alert-metadata]]
=== 获取警报元数据

+AlertsService_getMetadata+

返回有效的警报字段名称和数据类型。在查询警报之前调用此选项。



[[query-alerts]]
=== 查询警报

+AlertsService_queryForAlerts+

使用所选属性、筛选器、排序、时间限制和偏移分页查询活动或非活动警报。

必需输入：

* `active`
* `attributeNames`
* `fromTime`
* `toTime`
* `timezone`


可选输入包括 `filter`、 `sortField`、 `sortAscending`、 `limit`和 `offset`。 `limit`为 1-500； `offset`为 0-1000。请将时间窗保持在 30 天以内。

示例：

[]
====
检索过去七天的关键活动存储警报。返回警报 ID、监视器名称、严重性、状态和相关存储名称。

====


[[get-an-alert-by-name]]
=== 按名称获取警报

+AlertsService_getAlertByName+

使用采用 `AL-123456`格式的警报 ID 检索一个警报。

需要输入： `name`



[[get-an-alert-by-uuid]]
=== 按 UUID 获取提醒

+AlertsService_getAlertByUUID+

使用其 UUID 检索一个警报。

需要输入： `uuid`

[[logs]]
== 日志



[[list-log-types]]
=== 列出日志类型

+LogService_getLogTypes+

列出租户中当前可用的日志类型。



[[get-log-type-metadata]]
=== 获取日志类型元数据

+LogService_getLogTypeMetadata+

返回日志类型的有效属性。在搜索或分组事件之前调用它。

需要输入： `type`



[[query-log-events]]
=== 查询日志事件

+LogService_queryLogEvents+

返回按时间戳降序排列的日志事件。

必需输入：

* `type`
* `fromTime`
* `toTime`
* `timezone`


可选输入包括 `attributes`、 `filter`、 `limit`和 `cursor`。 `limit`为 1-200。事件窗口不能超过 30 天。传递上一个响应的游标以检索下一页。



[[count-log-events-over-time]]
=== 统计一段时间内的日志事件

+LogService_queryLogEventsCountHistogram+

返回固定大小的事件计数时间段。可选择按有效的可分组属性对每个时间段进行分组；分组结果返回顶部段和一个 +__other__+ 段。

必需输入：

* `type`
* `fromTime`
* `toTime`
* `timezone`


可选输入： `filter`、 `groupBy`

[[objects-and-metrics]]
== 对象和指标



[[list-object-types]]
=== 列出对象类型

+ObjectService_getObjectTypes+

列出租户中当前可用的对象类型。



[[get-object-metadata]]
=== 获取对象元数据

+ObjectService_getMetadataForObjectType+

返回一个对象类型的有效属性、指标、类型和分组功能。

需要输入： `objectType`



[[query-objects]]
=== 查询对象

+ObjectService_query+

检索对象、选定属性和可选指标。引用指标的筛选器在时间窗口聚合之前应用于原始值。

必需输入：

* `objectType`
* `attributeNames`


可选输入包括 `metricNames`、 `filter`、 `sortFieldName`、 `isSortAscending`、 `fromTime`、 `toTime`、 `aggregateFunctions`、 `limit`和 `offset`。

支持的查询聚合： `MAX`、 `MIN`、 `AVG`、 `SUM`、 `LAST`。 `limit` 为 1-500。如果省略时间限制，工具将默认为最近的三小时窗口。



[[group-objects]]
=== 组对象

+ObjectService_groupObjects+

按一个有效的可分组属性对对象进行分组，并聚合所选指标。过滤器适用于聚合前的原始值。

必需输入：

* `objectType`
* `groupByAttribute`
* `metricNames`


可选输入包括 `aggregateFunctions`、 `filter`、排序、时间限制、 `limit`和 `offset`。

支持的组聚合： `MAX`、 `MIN`、 `AVG`、 `SUM`、 `FIRST`、 `CHANGE`、+CHANGE_RATIO+。



[[query-performance-time-series]]
=== 查询性能时间序列

+ObjectService_queryPerformanceMetricsForObjects+

返回针对一个指标和匹配对象的分桶时间序列数据。

必需输入：

* `objectType`
* `metricName`
* `fromTime`
* `toTime`
* `timezone`


可选输入包括 `filter`、 `aggregationFunction`、 `limit`和 `isSortAscending`。 `limit`控制返回序列的数量，必须为 1-50。

支持的存储桶聚合： `MAX`、 `MIN`、 `AVG`、 `SUM`、 `FIRST`、 `CHANGE`、+CHANGE_RATIO+。

[[filter-operators]]
== 筛选运算符

警报、日志和对象查询支持嵌套条件：

* `EQ`, `NE`
* `GT`, `LT`, `GE`, `LE`
* `WILDCARD` 使用 `++*++`和 `?`
* `EXISTS`
* 嵌套 `and`、 `or`和 `not`


连接的服务器根据元数据验证字段。如果查询被拒绝，请刷新相关元数据并重构筛选器。
