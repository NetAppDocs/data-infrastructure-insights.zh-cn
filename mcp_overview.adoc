= DII MCP 服务器
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
将 AI 助手/代理连接到 Data Infrastructure Insights （DII），以便它们可以使用自然语言调查基础架构清单、遥测、警报和采集健康状况。


NOTE: DII MCP 是一项 link:concept_preview_features.html["预览"] 功能，因此可能会发生变化。

DII MCP 服务器实现模型上下文协议 (MCP)，并向受支持的 AI 客户端公开租户范围的工具。当前的产品工具集为*只读*：它检索和分析 DII 数据，但不修改基础架构或 DII 资源。



[[what-you-can-investigate]]
== 您可以调查的内容

* *基础架构清单：*存储、虚拟化、Kubernetes、ONTAP、Azure NetApp Files、StorageGRID 及相关资源。
* *性能和容量：*对象指标、分组聚合和时间序列行为。
* *日志和事件：* 发现日志类型、搜索事件和构建事件计数直方图。
* *警报：* 检查活动警报、监控定义、严重程度和纠正指导。
* *收集运行状况：* 查看采集单元、数据源、支持的收集器类型和 Kubernetes 收集器版本。
* *通知态势：*检查维护窗口、通知规则和 webhook 目标类型。

[[how-dii-mcp-queries-work]]
== DII MCP 查询的工作原理

许多 DII 资源具有动态架构。可靠的调查遵循发现优先的顺序：

. 列出可用的对象或日志类型。
. 检索选定类型的元数据。
. 仅使用该元数据中的有效属性和指标。
. 查询有界时间范围。
. 使用筛选器、分组、排序或分页来优化结果。


详情请参阅link:mcp_concepts.html["概念和数据模型"]。



[[important-limitations]]
== 重要限制

* 当前所有产品工具均为只读。
* 对象、性能和日志查询强制执行有界时间窗口。使用 30 天或更短的窗口，除非工具页面明确记录了较小的限制。
* 查询字段必须与为选定资源类型返回的元数据匹配。
* 大型结果会进行分页或限制上限。
* 工具可用性和返回的数据取决于租户的收集器、启用的功能和用户权限。
* 请勿请求或复制完整的 webhook 端点地址。请参阅 link:mcp_security.html["安全与隐私"]。
