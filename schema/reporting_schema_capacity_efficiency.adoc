实体集：date_dimension

|===

| fullDate | DateTimeOffset | 是 | 日期对象的日期。 


| dayInMonth | 字节 | 是 | 日期对象的月份日期。每月的第一天值为 1。 


| dayInYear | Int32 | 是 | 日期对象在一年中的第几天。一年的第一天值为 1。 


| dateYear | Int32 | 是 | 日期对象的年份。 


| yearLabel | 字符串 | 是 | 格式为字符串的年份 


| monthNum | 字节 | 是 | 日期对象的月份。1月的值为1。 


| monthLabel | 字符串 | 是 | 月份格式为字符串 


| dayInWeekNum | 字节 | 是 | 日期对象的星期几。星期日的值为 1。 


| 季度 | 字节 | 是 | 日期对象的季度。第一季度的值为 1。 


| quarterLabel | 字符串 | 是 | 季度格式化为字符串 


| dayInQuarter | Int32 | 是 | 日期对象的季度中的天。季度的第一天值为 1。 


| repQuarter | 字节 | 是 | 指示此日期是否是其季度的第一个可用日期。 


| repMonth | 字节 | 是 | 指示此日期是否是其月份的第一个可用日期。 


| repWeek | 字节 | 是 | 指示此日期是否是其一周内可用的第一个日期。 


| repDay | 字节 | 是 | 指示此日期是否是其当天可用的第一个日期。 


| repMonthOrLatest | 字节 | 是 | 指示此日期是代表月还是最新代表月。此标志由按月处理代表数据的 Datamarts 使用。唯一的区别在于当前月份使用的是最新数据 


| sspFlag | 字节 | 是 | 指示此日期是否在存储和存储池数据集市中使用。这适用于月代表和配置中定义的最后天数。 


| 最新 | 字符串 | 是 | 指示此日期是否为表中的最后一个可用日期。 


| 未来 | 字符串 | 是 | 指示此日期是未来日期（预测）还是常规日期。

[[top]]

实体集：efficiency_fact

[cols="1,1,1,1"]
|===
| 字段 | 类型 | 可为Null | 注释 


| tk *[PK]* | Int32 | 是 | 事实的 TK。 


| dateTk *[FK]* →link:#entity-date_dimension["日期维度"].tk | Int32 | 是 | 日期的 TK。 


| storageTk *[FK]* →link:#entity-storage_dimension["存储维度"].tk | Int32 | 是 | 容量所在存储的 TK。 


| 原始容量 MB | Int64 | 是 | 存储原始容量，以 MB 为单位。指定技术时为 0（不为 NULL）。 


| backendCapacityMB | Int64 | 是 | 虚拟阵列中后端 LUN 的总容量，以 MB 为单位。指定技术时为 0（不为 NULL）。 


| storageTechnology | 字符串 | 是 | 存储效率和保护技术，如重复数据删除、精简配置、快照和 RAID。表示存储的原始和后端容量时为 NULL（每个存储一行）。 


| gainMB | Int64 | 是 | 使用技术获得的容量。未指定技术时为 0（NULL）。 


| lossMB | Int64 | 是 | 使用技术时损失的容量。未指定技术时为 0（NULL）。 


| potentialGainMB | Int64 | 是 | 通过充分利用技术可获得的潜在容量。未指定技术时为 0（NULL）。 


| potentialLossMB | Int64 | 是 | 充分利用技术可能造成的容量损失。未指定技术时为 0（NULL）。 
|===
